#  Transport Management System (TMS)

A Transport Management System (TMS) developed to simplify and manage transportation operations efficiently. This system helps administrators manage vehicles, drivers, routes, bookings, and customers through a user-friendly interface.

## Features

- User Authentication (Login & Registration)
- Dashboard
- Vehicle Management
- Driver Management
- Route Management
- Booking Management
- Customer Management
- Reports

## Technologies Used

- HTML
- CSS
- JavaScript
- SpringBoot
- MySQL
- Git
- GitHub
